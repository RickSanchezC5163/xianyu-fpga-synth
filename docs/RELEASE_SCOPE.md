# 公开快照范围

本仓库创建于 2026-11-03，独立于原私有研发仓库，不迁移私有提交历史。原仓库的可见性不作改变。

保留：音频/USB/UI/引导 RTL、板级约束、测试平台、S3 固件、网页源码与自包含网页资源、原创演示谱、构建和回归入口、第三方许可。

移除或替换：第三方歌曲及 MIDI 衍生曲库、音频录制、个人报告、聊天截图、私人文件路径、转储文件、工具安装包、烧录二进制、历史日志、原仓库链接和未公开个人身份信息。示例热点密码是公开开发默认值，部署时须通过 menuconfig 更改；真实路由器凭据不内嵌源码。

屏幕 HMI/TFT 工程与完整机械/供电 CAD 未纳入本次发布。RTL 中的屏端协议、页面状态和数据发送逻辑可供研究，但完整复现实物仍需要匹配的屏幕工程、USB 设备和硬件。USB Host 当前使用经过验证的特定设备配置，接其他型号前应检查描述符、VID/PID 和端点。

公开版只附原创练习，不附报告展示中使用的商业曲目。测试中的曲名字符串仅用于验证中文编码及元数据，不包含对应乐曲内容。

本仓库为非商业公开源码，不能将其许可描述为 MIT、Apache-2.0 或无限制开源。USB Host 上游代码仍保留 Apache-2.0；前端依赖按各自许可提供。
