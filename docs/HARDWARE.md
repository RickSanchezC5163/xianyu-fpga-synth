# 硬件接口

基线：Tang Mega 60K + NEO Dock，ESP32-S3 N16R8，陶晶驰 TJC4827T143-011C-P20，USB MIDI 兼容输入设备，以及 5V 可编程灯带。管脚依据 `rtl/boards/mega60k/tjc_wifi_ui.cst`；连接前核对自己的底板版本。连接器针号不是从照片左右方向猜出的编号。

| 外设信号 | FPGA 位置 | 方向 |
|---|---|---|
| S3 GPIO4 / TX | J9.7 / P16 / wifi_rx | S3 → FPGA |
| S3 GPIO5 / RX | J9.8 / R17 / wifi_tx | FPGA → S3 |
| 屏幕 TX | J9.9 / T21 / screen_rx | 屏幕 → FPGA |
| 屏幕 RX | J9.10 / U21 / screen_tx | FPGA → 屏幕 |
| 公共地 | J9.3 或 J9.4 / GND | 共地 |
| 延迟控制标记 | J8.5 / AA19 / debug_control | FPGA → 示波器 |
| 数字样本标记 | J8.6 / AB20 / debug_pcm | FPGA → 示波器 |

串口信号采用 3.3V 兼容电平；屏幕的 5V 电源不能接到 FPGA GPIO。屏幕接 FPGA 时不要同时连接 USB 转 TTL 的 TX。S3 可用自身 USB 供电，数据线按 TX→RX 交叉连接。

USB-A 留给 MIDI 键盘，保持底板 USB 路由开关处于 FPGA 位置；CH569 接口和 USB DEBUG 不是屏幕 UART 接口。

## 灯带

实物灯带接 NEO Dock 板载 WS2812 扩展接口：J24.1 为 GND、J24.3 为数据、J24.4 为板载 5V，J24.2 缺针。灯带输入接 DIN，不能接 DOUT；板载灯与外灯的级联偏移由 RTL 处理。按实际底板原理图确认电源能力，不能据此推断允许整米灯带满亮白光。

当前校准针对 15 白键、整排宽约 292 mm、灯距约 10 mm 的 25 键键床：最左白键对应外灯第 2 颗，最右白键第 30 颗，第 31/32 颗用于节拍/范围提示。编号从外灯 DIN 端按 1 起算。换键床、安装偏移或灯密度后，应重新修改 `guide_led_frame.v` 的映射并逐键验证。

## 音频与首次上电

板载 PT8211 使用其对应音频串行格式；标准 I²S 输出由独立 RTL 提供。两者不能仅凭同为三根信号线混接。外置 PCM5102 的模块跳线、供电、格式和模拟输出负载需独立核对，本仓库不宣称该路径已完成模拟音质验收。

当前生产配置可能以较大数字音量启动。首次部署前先降低外部功放音量，再从单音开始验证；不要把未经检查的位流直接用于高音量耳机试听。
