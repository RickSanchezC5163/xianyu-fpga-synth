首次使用 / 更换路由器

先连接 ESP 设置热点打开本页，填写与手机/电脑相同的 2.4GHz Wi‑Fi。获得局域网地址后，切回该 Wi‑Fi，用新地址打开曲库。设置热点保留作为备用入口。

本页不回显密码；忘记路由器只移除配网信息，不清空曲库。连接信息只用于此设备，不上传云端。

声音、节拍和灯光时基由 FPGA 执行。ESP 仅管理网络和符号曲谱传输。
